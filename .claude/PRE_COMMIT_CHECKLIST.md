# Pre-Commit Checklist

**MANDATORY: Complete ALL items before claiming work is done**

## ✅ Testing and Verification
- [ ] All tests are passing (`npm test`)
- [ ] No failing tests exist
- [ ] Changes tested in browser/application (not just locally)
- [ ] API endpoints verified to work correctly
- [ ] UI changes render properly
- [ ] Backend and frontend integration functioning

## ✅ Session History Logging
- [ ] Entry added to `/notes.md` using the template:
  - Date: YYYY-MM-DD
  - Tasks: (bullet list of what was completed)
  - Follow-ups: (bullet list of outstanding items or "None")
- [ ] Entry is accurate and complete
- [ ] Blank line added after entry for readability

## ✅ Test-First Development
- [ ] Tests created BEFORE or ALONGSIDE implementation
- [ ] All new functionality has tests
- [ ] Tests cover edge cases and error handling
- [ ] All tests passing before committing

## ✅ Communication
- [ ] Not claiming fixes work without verification
- [ ] Being honest about limitations and uncertainties
- [ ] Asking for verification when unsure
- [ ] Not being overconfident about results

## ✅ Code Quality
- [ ] Following existing code patterns
- [ ] Maintaining consistency with codebase
- [ ] Proper error handling and validation
- [ ] Complex logic documented

---

**REMINDER**: If ANY item is unchecked, the work is NOT complete.
